🌱 Beginner guide — zero to professional

Step 0 — 3 ideas (2 min)

Interest: simple K0·(1+n·i) vs compound K0·(1+i)ⁿ → continuous K0·e^{i·n}.
Present value: future €1,000 = 1000/(1+i)⁵ today; duration = average arrival time.
Optimization: linear = Simplex/duality; integer = Branch-and-Bound (rounding fails).

Step 1 — Run (1 min)

pip install -r requirements.txt
python -m pytest tests -q
PYTHONPATH=. python experiments/exp01_zins_verification.py

Step 2 — Change one number (2 min)

from src.finanzmathematik import zinseszins_endwert, annuitaet
print(zinseszins_endwert(20000, 0.06, 10))  # try 0.04
print(annuitaet(40000, 0.05, 5))
